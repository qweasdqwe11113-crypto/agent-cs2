# CS2 Demo 分析 Agent

面向完美世界竞技平台 CS2 回放的赛后复盘工具。用户上传平台下载的 demo ZIP 或原始 `.dem` 文件，系统解析比赛事件并生成可验证的中文复盘与训练建议。

> 产品边界：仅做赛后、离线分析；不读取运行中游戏数据、不提供实时提示、不执行游戏操作。

## MVP 目标

完成一条可靠的主流程：

```text
上传 Wmpvp demo ZIP / .dem
  -> 提取并校验 .dem
  -> 解析 CS2 回放事件
  -> 计算基础指标与关键回合
  -> 生成中文复盘报告
```

首版报告包含：

- 对局基本信息：地图、回合比分、玩家、阵营结果；
- 回合时间线：首杀、击杀、下包、拆包、回合结果；
- 玩家指标：K/D、ADR、首杀/首死、残局、经济与道具使用；
- 自动筛选 3--5 个关键回合；
- 每个关键回合的事实证据、原因解释和可执行建议。

## 完美世界竞技平台 Demo

平台本地回放通常位于：

```text
%APPDATA%\\Wmpvp\\demo\\<match-id>_0.zip
```

例如 `9208913834384608937_0.zip` 内部直接包含同名 `.dem` 文件。导入模块需要同时支持 ZIP 和 `.dem`：

1. 校验文件大小、扩展名和 ZIP 完整性；
2. ZIP 仅提取 `.dem` 文件，拒绝异常路径与其他内容；
3. 记录原始文件名、解析器版本和 demo 协议版本；
4. 从 demo 内容读取地图、玩家 SteamID、比赛时间等可信元数据；
5. 解析失败时明确提示不支持的版本，不生成猜测性结论。

不依赖非公开平台接口；首版采用用户手动上传回放的方式。

## 架构

```text
Import Service
  ZIP/.dem 校验、解压、文件存储
        |
Demo Parser
  tick 与比赛事件提取
        |
Analysis Engine
  指标计算、回合标签、关键回合与规则证据
        |
Coach Agent
  基于证据生成中文复盘、问答和训练建议
        |
Web UI
  报告、时间线、地图回放与追问
```

解析与分析引擎负责产生确定性事实；LLM 只负责解释、组织报告和回答基于证据的问题。每条结论必须能定位到具体回合、事件和地图位置。

## 迭代计划

### Phase 1：单局复盘

- ZIP / `.dem` 导入；
- 标准 5v5 Competitive 对局解析；
- 基础统计、回合时间线和关键回合报告；
- 优先支持常见地图（Mirage、Dust2、Inferno）。

### Phase 2：个人教练

- 多局历史数据与地图/阵营画像；
- 首死、补枪、死亡位置、道具效率等重复问题检测；
- 按周输出训练建议与待复盘回合。

### Phase 3：团队战术

- 默认、快攻、慢摸等回合类型识别；
- 补枪链、转点、道具协同与残局转化分析；
- 固定队伍的团队报告与对手习惯分析。

## 待确定的技术选择

- Demo 解析器：选择持续维护且支持当前 CS2 demo 协议的开源库；
- 后端：FastAPI 或 NestJS；
- 数据：PostgreSQL 保存结构化对局数据，Parquet / 对象存储保存高频 tick 数据；
- 异步任务：Redis + Celery 或 BullMQ；
- 前端：React + TypeScript，地图回放使用 Canvas 或 WebGL。
